# Accessibility — WCAG 2.2 AA Target

## Required
- semantic HTML
- keyboard complete
- focus visible
- accessible form labels
- error messages associated with fields
- skip link
- correct heading order
- sufficient contrast
- touch targets around 44px or larger
- no color-only meaning
- reduced motion
- screen-reader friendly map alternative
- language metadata
- accessible charts/calculator output

## Rural/device considerations
- works on small Android phones
- no hover-only functionality
- no tiny text
- no auto-playing video
- low bandwidth
- meaningful loading states

## Maps
Provide list/table view in addition to map view so users who cannot use maps still get:
name, address, phone, distance, supported scheme and status.

## Testing
Run automated axe checks plus manual keyboard and screen-reader testing.
